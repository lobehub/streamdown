## Completing the tail

Mid-stream, markdown is almost always unbalanced. Before the open tail block is lexed, Streamdown runs it through [remend](https://github.com/vercel/streamdown), which completes unclosed markers such as emphasis, inline code, links and strikethrough. Only the tail is processed; frozen blocks are already complete.

## Options

Pass remend options through the `remend` prop. For example, use `{ htmlTags: false }` when `<` in your content is prose or math rather than HTML:

```tsx
<Streamdown content={content} remend={{ htmlTags: false }} />
```

The same options are applied by the smoother (`useSmoothStreamContent`) and the block lexer, so both see the same completed tail.
