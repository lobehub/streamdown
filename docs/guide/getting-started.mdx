This page takes you from install to a streaming message with tables and math in a few minutes. New to the problem Streamdown solves? Read the [Introduction](/guide/introduction) first.

## Requirements

- `react` and `react-dom` `^19` (peer dependencies).
- An ESM toolchain: the package ships ESM only.

It includes a `'use client'` boundary, so it renders from React Server Component frameworks without extra wiring.

## Installation

```bash
pnpm add @lobehub/streamdown
```

## Render a stream

Pass the markdown received so far as `content` and re-render as chunks arrive. There is nothing to reset between chunks: Streamdown keeps finished blocks cached and only re-lexes the open tail.

```tsx
import { Streamdown } from "@lobehub/streamdown";

export const Message = ({ content }: { content: string }) => (
  <Streamdown content={content} />
);
```

## Add GFM and math

Plugins are passed through to react-markdown. When you render math, enable `latexGuard` so a half-arrived formula keeps the previous frame instead of flashing raw source.

```tsx
import { Streamdown } from "@lobehub/streamdown";
import rehypeKatex from "rehype-katex";
import remarkGfm from "remark-gfm";
import remarkMath from "remark-math";
import "katex/dist/katex.min.css";

export const Message = ({ content }: { content: string }) => (
  <Streamdown
    content={content}
    latexGuard
    rehypePlugins={[rehypeKatex]}
    remarkPlugins={[remarkGfm, remarkMath]}
  />
);
```

## Style it

Streamdown ships no stylesheet, so the output inherits your typography. Swap elements such as `pre` through `components`; see [Components & Plugins](/content/components).
